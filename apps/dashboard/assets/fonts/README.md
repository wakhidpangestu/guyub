# Fonts

Plus Jakarta Sans, Public Sans, and JetBrains Mono are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). The license texts are in `licenses/`. The static TTF files come from Google Fonts and cover the Latin subset. They are bundled so the app does not call a font CDN at runtime. For other scripts, Flutter web falls back to its own Noto fonts.

See `design-system/guyub/MASTER.md` for which font is used where.
